# 대화 로그 정리기 v3 — GitHub Pages 바로 덮어쓰기

**이 ZIP의 파일은 모두 ZIP 최상위에 있습니다.** 저장소 루트에 그대로 업로드하세요. `chat-log-cleaner` 폴더를 별도로 만들지 마세요.

## 기존 GitHub Pages 업데이트

1. ZIP 압축을 풉니다.
2. GitHub 저장소 `Code` → `Add file` → `Upload files`에서 압축을 푼 **같은 이름의 파일**을 업로드합니다.
3. `Commit changes`를 누릅니다. 저장소 삭제나 기존 파일 삭제는 필요 없습니다.
4. `Actions` 또는 `Settings → Pages`에서 배포가 끝났는지 확인합니다.
5. 페이지를 강력 새로고침(Ctrl+Shift+R / Mac Cmd+Shift+R)합니다.
6. 상단 **`v3 · 화자별 묶기`**와 `화자별로 연속 대화 묶기` 체크박스가 보이면 성공입니다.

업로드할 웹사이트 파일: `index.html`, `app.js`, `cleaner.js`, `styles.css`. `README.md`도 업데이트할 수 있습니다. `test.js`는 선택 사항입니다.

## 새 기능

화자별 연속 대화 묶기 옵션(기본 켜짐):

```text
담비 : 다들 오해예요
이랑 : 피에트로본인도헷갈릴듯
이랑 : 너남친있어. . . ?
담비 : 아뇨헤어졌는데요
담비 : 이래서 헤어졌어요(찌질해서)
```

결과:

```text
[담비]
다들 오해예요
[이랑]
피에트로본인도헷갈릴듯
너남친있어. . . ?
[담비]
아뇨헤어졌는데요
이래서 헤어졌어요(찌질해서)
```

- 날짜/시간 접두사 제거
- `ㅋ`, `ㅎ`, `ㅠ`, `ㅜ`로만 구성된 메시지 삭제(설정 가능)
- 빈 줄 제거
- 원본·정리 후 미리보기, TXT 다운로드
- 모든 처리는 브라우저 로컬에서만 진행되며 외부 서버로 TXT를 업로드하지 않습니다.
