# 대화 로그 정리기

대화 기록이 담긴 TXT 파일을 브라우저에서 읽기 편한 형식으로 정리하고, 정리된 내용을 새 TXT 파일로 저장하는 무료 정적 웹사이트입니다. 별도 회원가입이나 프로그램 설치가 필요하지 않습니다.

## 주요 기능

- 카카오톡 TXT 내보내기 형식의 날짜 및 시간 접두사 제거
- 화자 이름과 메시지 본문 보존
- 동일 화자가 연속으로 보낸 메시지를 하나의 화자 구역으로 묶기
- **연속 메시지 한 줄로 합치기:** 연달아 보낸 메시지를 공백으로 연결 (기본 켜짐)
- `ㅋ`, `ㅎ`, `ㅠ`, `ㅜ` 등 지정한 문자만으로 이루어진 메시지 필터링
- 불필요한 빈 줄과 날짜 구분선 제거
- 원본 및 정리 결과 미리보기, TXT 다운로드
- UTF-8 / CP949 인코딩 지원 (최대 30MB)

모든 정리는 **사용자의 브라우저 안에서만** 진행됩니다. 업로드한 TXT의 내용은 웹 서버로 전송되지 않으며, 원본 파일도 수정되지 않습니다. 단, 공개 GitHub 저장소에 개인 대화 기록을 직접 커밋하지 않도록 주의해 주세요.

## 사용법

1. 웹사이트에서 TXT 파일을 선택하거나 파일을 끌어다 놓습니다.
2. 필요한 정리 옵션을 선택합니다. 결과 미리보기가 즉시 갱신됩니다.
3. **정리된 TXT 다운로드**를 눌러 결과 파일을 저장합니다.

연속 메시지 한 줄로 합치기는 **화자별로 연속 대화 묶기** 기능과 함께 작동합니다. 화자별 묶기를 끄면 원래의 `화자 : 메시지` 형식으로 표시됩니다.

## GitHub Pages에 배포하기

저장소 최상위에 아래 파일을 올립니다.

- `index.html`
- `styles.css`
- `cleaner.js`
- `app.js`
- `README.md`

기존 사이트를 업데이트하는 경우 같은 이름의 파일을 업로드해 커밋하면 됩니다. 저장소를 삭제하거나 새로 만들 필요가 없습니다. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택하세요. 배포 후 새 화면이 표시되지 않으면 강력 새로고침을 사용해 보세요.

## 개발자용 검사

Node.js가 설치된 환경에서 다음 명령으로 텍스트 정리 로직의 테스트를 실행할 수 있습니다.

```sh
node test.js
```

이 프로젝트는 HTML, CSS, JavaScript로 구성되어 별도 빌드 단계가 필요하지 않습니다.
